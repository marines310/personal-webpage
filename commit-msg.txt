Make the two models this world had code for and no files for

addRock() and addStreetlight() have both opened with "if the model is there,
use it" since the day they were written, and neither branch had ever run,
because nobody had the files. tools/makeModels.mjs writes them.

They are generated, not downloaded, and they match because they take their
colours from the SAME Textures/colormap.png the Kenney models sample - the
mesh carries UVs and the colour lives in the picture, so these are not
"painted to look similar", they are literally the same paint. The atlas is a
16x16 grid of 32px cells; every swatch the generator uses is asserted against
the real file on every run, so if one moves the run fails rather than quietly
producing grey rocks. Flat shading is in the geometry - one normal per
triangle - so it survives cloning and scaling.

rock.glb is 3.5KB, 20 triangles, a jittered icosahedron squashed to 1.79 x
1.12 x 1.69: wider than tall, because a rock in grass is not a ball, and not
so flat that its cube collider is a lie. Jitter is a fixed table rather than
Math.random(), because a file that comes out different every time it is
generated cannot be diffed or tested.

streetlight.glb is 12.6KB, 92 triangles, built to the built-in shape's exact
dimensions - a 4.6 pole with the arm reaching x=0.85 - because everything
that places a lamp is positioned against those numbers. Hence NO fitLength on
its manifest entry, which is the line here most likely to be tidied away by
someone later.

AND THE THING THAT WOULD HAVE SHIPPED A REGRESSION. The streetlight model
path registered no night light and cast no pool of light. Since it had never
run, nobody had noticed - so the day a streetlight.glb appeared, every lamp
in the world would have stopped coming on at dusk and every pool of light on
every road would have gone with it. Better geometry, darker night: exactly
the failure already written up at addBuilding(), lighting written for a code
path the game never takes. The model path now does both, the lens is its own
material in the .glb so the pole does not glow with it, and the pool is one
addLampPool() that both paths call.

tests/models.mjs, 28 checks, reads the bytes off disk rather than trusting
the generator - this project has paid twice for trusting a number over the
asset. The two load-bearing checks were negative-tested: pointing the arm
along -X fails the orientation check, and deleting the registerNightLight
call fails the night check.

All 46 suites pass.
