To apply your map:
  1. Hit Download mapData.js
  2. Move it into src/world/, replacing the file already there
  3. The dev server reloads by itself — check it looks right
  4. To publish it: GitHub Desktop → Commit to main → Push origin. Live in about 90 seconds.
